

# Naming Conversions
Earlier versions of the code had some different naming. Mappings are recorded here:

- `saturating_time_at_rest_from_velocity` -> `idleness_encoding`
- `saturating_progress_from_step_count` -> `saturating_progress_encoding`
- `geometric_sinusoidal_encoding` -> `sinusoidal_progress_encoding`
- `geometric_progress_encoding_dim` -> `sinusoidal_progress_encoding_dim`

- `VT` was shorthand for idleness, now its `ID`
- `SP` was shorthand for saturating progress, now its `SaP`
- `GP` was shorthand for sinusoidal progress, now its `SiP`
